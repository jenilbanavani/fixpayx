# PayQR Android app project

This is an Android Studio project for a small native Android app.

## What it does
- First launch: asks for the merchant UPI ID once.
- Stores the UPI ID on the device using Android SharedPreferences.
- Every later launch: amount input -> Make payment QR.
- QR image can be saved to Pictures/PayQR or shared.
- No account, password, shop profile, backend, or payment collection.

## Build an APK
1. Install Android Studio on a computer.
2. Open this folder (`PayQR_Android`) in Android Studio.
3. Allow Gradle sync and install the Android SDK 35 if prompted.
4. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Android Studio will show the generated APK location, usually `app/build/outputs/apk/debug/app-debug.apk`.

The first Gradle sync needs internet to download Android Gradle Plugin, AndroidX Core, and ZXing.

## Important payment limitation
The QR uses a standard UPI payment URI with the amount prefilled (`am`). Some UPI apps may still let the payer edit the amount. A standard static/prefilled UPI QR cannot guarantee a locked amount. For guaranteed amount enforcement, integrate a payment provider's dynamic QR flow.

## Before distributing to customers
This is a starter build, not yet a signed production release. Test QR scans in Google Pay, PhonePe, Paytm and your target UPI apps. Verify the payee name and amount before accepting it. For Play Store or wider distribution, create a release signing key and review privacy, support and payment-provider requirements.

## Build the APK using GitHub from a phone (no Android Studio required)
1. Create a new GitHub repository.
2. Extract this ZIP and upload all project files/folders to the repository (including the hidden `.github` folder and workflow file). GitHub's web interface may require uploading the files in folders separately.
3. Open the repository's Actions tab.
4. Select **Build PayQR APK** and tap **Run workflow** (or wait for the main-branch push build).
5. When the workflow completes, open the run and download the **PayQR-debug-apk** artifact.
6. Extract the downloaded artifact ZIP; it contains `app-debug.apk`. Install it on the Android phone and allow installation from that source if Android asks.

The APK generated by this workflow is a debug APK for testing. A release APK for public distribution must be signed separately.
